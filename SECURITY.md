# Security Policy

## Supported versions

Security fixes are applied to the latest release of this package.

## Reporting a vulnerability

Please **do not** open a public GitHub issue for security problems.

Report privately via [GitHub Security Advisories](https://github.com/Johnrivera7/filament-mia-theme/security/advisories/new), or email **johnriveragonzalez7@gmail.com**, with:

- A description of the issue
- Steps to reproduce
- Impact assessment (if known)

You will receive an acknowledgement, and a fix or mitigation plan, as soon as practical.
